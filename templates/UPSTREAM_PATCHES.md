# 上游补丁台账模板

当前设计包未应用任何候选上游SDK补丁。以下字段供实际需要窄补丁时填写。

| 字段 | 要求 |
|---|---|
| 组件/任务 | 精确component_id与OB任务 |
| 上游来源 | repository、issue/PR、锁定release/commit与源码hash |
| 问题重现 | 受控夹具、失败证据、受影响平台与版本 |
| 最小改动 | 文件、diff、原因；不得顺便放宽权限或重试 |
| 许可证 | 保留LICENSE/NOTICE和修改标识 |
| 回归 | 正常、失败、取消、超时、升级测试 |
| 退出条件 | 上游修复版本、替换计划、维护人、复查触发 |

优先使用满足合同的上游正式修复。确需补丁时使用可复查的补丁文件或固定分支；不使用未记录的全局monkey-patch，也不把历史issue号码当作当前版本仍有漏洞的证明。
