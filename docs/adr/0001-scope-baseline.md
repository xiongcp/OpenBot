# OB-001：实施范围基线

状态：接受；日期：2026-11-04；责任：本轮 Integrator。

沿用设计包 A01—A10：一个 OS 用户、profile、owner、执行设备；一个自建飞书应用只对应一个活动 gateway。渠道、CLI 与后置 Tauri 仅是入口。M0 合同和 mock 协议、M1 本地闭环、M2 真实飞书、M3 两 Provider / Browser / MCP / 三平台 CLI、M4 桌面安装分别验收。P2 不在本轮范围。

首测为实测 Darwin arm64；其他 OS 尚未验证。首个云 Provider 选择受限 OpenAI 基础请求适配器；第二 Provider 为 Ollama 候选，只有本地来源、禁云和出口证据齐全才提供 LOCAL_MODEL。没有真实账号或隔离后端不扩大权限、不切换宿主执行。

原要求：S01—S06 与 M3 能力；建议：macOS ARM64 优先、Python 3.12；未验证：真实飞书租户、模型凭据、Windows/Linux 原生环境、Docker 后端。项目自身源码许可尚未由用户选定，不替用户声明开源许可证；第三方许可独立核验。

三主场景审查：S01 代码诊断→RQ01/RQ05/RQ07（只读和提案经 Broker）；S02 隔离验证→RQ04/RQ05/RQ06（绑定快照与权限）；S03 崩溃恢复→RQ02/RQ03/RQ10（不确定结果进入核对）。

五失败场景审查：无 owner 的飞书消息→RQ04/RQ08 拒绝；取消后请求派发→RQ03/RQ05 拒绝；未知外部结果→RQ03/RQ10 隔离资源；无容器后端→RQ05 拒绝；缺原生平台证据→RQ11/RQ12 不授予 supported。S04 接管不声称外部动作回滚；S05 浏览器按具体动作授权；S06 OFFLINE 不承诺整机断网。

范围改变须同步 ADR、合同、任务及验收。不存在“支持所有任务”的承诺；M1 或 M2 不能宣称 M3 已完成。
