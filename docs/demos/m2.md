# M1 安全工具威胁回归与 M2 准入边界说明 / M1 Security Tool Threat Regression & M2 Entry Gate (OB-045)

## 中文说明

### 1. 威胁回归语料与零未授权副作用断言
`services/core/src/openbot/policy/threat_regression.py`（`M1ThreatRegressionSuite`）与 `tests/security/test_m1_threat_regression.py` 在 M1 门禁中直接对真实文件守卫、JCS 序列化、进程协议、秘密代理和进程树监管执行 7 类攻击与故障回归，断言 `total_unauthorized_side_effects == 0`：
1. `jcs_deep_mutation_and_duplicate_key`：Pydantic/Python 嵌套对象在 JCS 冻结后发生深层变异时立即检出哈希不一致；重复 JSON 键在解析入口直接抛出 `ContractError`。
2. `path_traversal_and_symlink_escape`：`../` 越界、指向工作区外的符号链接以及 `.git/hooks/*` 路径读取均被 `WorkspaceFileGuard` 阻断。
3. `rg_and_git_malicious_config_injection`：`build_pinned_ripgrep_command` 强制注入 `--no-config`、`--no-pre`、`--no-follow` 并剥离 `RIPGREP_CONFIG_PATH`、`GIT_CONFIG_GLOBAL`、`LD_PRELOAD`。
4. `parser_runtime_download_and_crash_isolation`：`PinnedGrammarRegistry` 拒绝加载位于工作区内的 grammar 二进制，对未离线安装的语言返回 `CAPABILITY_UNAVAILABLE`，绝不运行期联网下载。
5. `secret_leak_and_offline_scanner_enforcement`：`SecretBroker` 拒绝 `model_prompt` 等非授权上下文读取密钥；`RedactionPipeline` 离线剥离密钥且 `network_verification_enabled = False`。
6. `output_flood_truncation_and_shell_metachar_rejection`：`ProcessExecutionPlan` 拒绝 `/bin/sh -c` 等宿主 shell 包装；`ControlledProcessExecutor` 对超出 `max_output_bytes` 的输出流式截断并标记 `output_truncated = True`。
7. `unisolated_worker_residual_blocks_new_dispatch`：当进程树回收发现残留子进程 PID 时，`ProcessSupervisorService` 强制返回 `quarantine_required = True` 且 `new_dispatch_allowed = False`。

### 2. 可复现验证命令
- `PYTHONPATH=services/core/src .venv-m1/bin/python -m pytest tests/security/test_m1_threat_regression.py -q`（1 passed）

## English Summary

### 1. Threat Regression Corpus & Zero Unauthorized Side-Effect Assertions
`services/core/src/openbot/policy/threat_regression.py` (`M1ThreatRegressionSuite`) and `tests/security/test_m1_threat_regression.py` verify 7 security and recovery invariants directly against real guards in M1 (`total_unauthorized_side_effects == 0`):
1. `jcs_deep_mutation_and_duplicate_key`: Detects post-canonicalization deep mutations and rejects duplicate JSON keys with `ContractError`.
2. `path_traversal_and_symlink_escape`: Blocks `../` traversal, symlink escape outside the workspace, and `.git/hooks/*` access.
3. `rg_and_git_malicious_config_injection`: Forces `--no-config`, `--no-pre`, `--no-follow` and strips `RIPGREP_CONFIG_PATH`, `GIT_CONFIG_GLOBAL`, and `LD_PRELOAD`.
4. `parser_runtime_download_and_crash_isolation`: Rejects workspace-resident grammar binaries and fails closed with `CAPABILITY_UNAVAILABLE` without runtime downloads.
5. `secret_leak_and_offline_scanner_enforcement`: Blocks `model_prompt` secret resolution and redacts secrets offline with `network_verification_enabled = False`.
6. `output_flood_truncation_and_shell_metachar_rejection`: Rejects `/bin/sh -c` wrappers and truncates output floods at `max_output_bytes`.
7. `unisolated_worker_residual_blocks_new_dispatch`: Enforces `quarantine_required = True` and `new_dispatch_allowed = False` when residual worker PIDs remain.

### 2. Reproducible Command
- `PYTHONPATH=services/core/src .venv-m1/bin/python -m pytest tests/security/test_m1_threat_regression.py -q` (`1 passed`)
