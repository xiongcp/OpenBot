# v1.2修订记录与实施顺序

## 本轮变更范围

输入是新增的U3《OpenBot 开源组件复用评估.pdf》（27页，包括第2与11页图表），对照本轮之前的v1.1设计包。采纳其复用方向，针对官方资料与源码核验后修订边界。表内“采用”均表示设计选择，真实组件资格验证仍是后续任务。

保留原88个任务ID与阶段，新增OB-089至OB-096，共96项；增加组件关联、复用方式与验收说明。原有23张SQL表、14个本地API操作、四对象状态及UNKNOWN恢复语义保持。新增6项ADR，累计22项；架构图增加复用边界图，累计7张。组件目录包含52个组件或组件组，所有实际准入状态从NOT_RUN开始。

## 对编码助手的交接变化

每轮除了原有依赖和验收，还要读取task的component_refs、reuse_type与reuse_notes，并核对components/catalog.json的决策。候选与参考项不能仅因出现在任务中就安装或复制。完成一个准入任务不意味着后续所有适配器自动通过；必须记录精确组件与平台组合。

AGENTS、CLAUDE和prompts已经同步：常规可逆实现可以连续推进；无真实环境时完成可独立部分并继续其他就绪任务；不通过放宽权限、添加宿主fallback、忽略未知结果或声称未跑测试来完成任务。沿用既有用户授权，不为了常规组件替换增加无必要确认。
