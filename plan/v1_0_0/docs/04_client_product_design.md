# 客户端与用户流程设计

## 用户要完成的三件事

第一次使用能连接模型和工作区；执行中能知道发生了什么、为何等待、怎样停止；出现问题能看到结果是否确定以及下一步如何核对。UI 以这些任务组织，而不是把数据库表、运行 epoch 和内部路径直接暴露给普通用户。

## 六个主要界面

| 界面 | 必需内容 | 关键交互 |
|---|---|---|
| 上手/连接 | daemon 状态、模型与网络模式、工作区、可用执行后端 | 分步验证；无凭据/无隔离给修复入口；不能假成功 |
| 任务列表/详情 | 目标、状态、等待原因、时间、结果链接、预算 | 新建、取消、查看审批、复制脱敏诊断 |
| 审批中心 | 具体动作、目标、Diff/数据外发、有效期、版本 | 批准一次/拒绝；过期或目标变更显示重新提案 |
| 执行图/时间线 | 事实节点、父子关系、公开计划摘要、回执和产物 | 同步选中图与列表；只读回放；键盘可操作 |
| 设置 | 模型、网络、限额、技能/MCP/飞书开关、语言 | 预览差异→确认应用→显示实际激活状态 |
| 健康/恢复 | 各组件状态、未知结果、连接恢复、备份与诊断 | 导出前预览；核对向导；不提供“强行标成功” |

## 任务详情布局

左侧为任务与筛选，中间显示任务目标、状态和事实时间线，右侧为选中事件的证据/产物与审批详情。小屏幕改为任务→详情→证据的分层视图，保留固定的停止/待审批入口。图视图是辅助；完整信息必须也能通过线性列表阅读。

状态除了颜色还必须有图标和文字：等待批准、执行中、已完成、部分完成、失败、已停止继续执行、结果待核对。UNKNOWN 采用明确的黄色提示，解释“动作可能已经发生，正在核对”，不能翻译成失败后重试。

## 一次受控修改的用户流程

1. 用户选择明确工作区，输入目标。
2. 显示系统接受任务与当前模式，不提前显示完成。
3. 产生补丁后展示文件、旧版本、精确 Diff 和会影响的范围。
4. 用户批准，服务端复验。目标变化时展示冲突和“重新生成提案”。
5. 执行后展示实际产物与验证结果，失败则给可操作原因。
6. 用户可随时停止后续派发；如果已有在途动作，持续显示核对状态。

## Tauri 的职责

采用活动分支提出的 Tauri 2 薄壳方向，初期静态 ES modules/CSS/SVG，避免为小客户端额外引入复杂状态框架。以 Rust 固定 command 代理调用既有本地 API，凭据只驻留受限原生状态；WebView 不获得广域 token、任意 URL 请求、宿主 shell 或任意文件路径能力。[R04]

按当前计划，第一版可连接已由 CLI 启动的 profile，但这只能作为开发 alpha。用户 beta 必须补安装、启动、配对、缺失能力诊断等上手流程。Tauri capabilities/CSP 与 OpenBot 业务授权是两层不同控制，两者都要做反例测试。[W03]

## 必须设计的异常状态

没有模型凭据；模型没有工具能力；本地模型未安装；容器后端未启动；权限收紧；审批过期；任务超预算；流中断且计费未知；浏览器 target 变化；MCP 工具表改变；daemon 重启；事件游标过期；磁盘空间不足；升级不兼容；Keychain 锁定；飞书断线；未知效果尚未核对。

每种异常包含四项：发生了什么、当前已知/未知结果、用户可以做什么、系统继续禁止什么。面向用户的文案避免展示长堆栈；技术细节在可展开的诊断中提供，并默认脱敏。

## 中英、可访问性和隐私

所有用户文案使用稳定 i18n key；测试 zh-CN/en 的长文案、日期/数字/时区、路径含中文与空格。图、表格、按钮具有可读名称；键盘焦点清晰，弹窗关闭后返回触发控件，减少动态效果时停止非必要动画。目标 WCAG 2.2 AA，具体标准见网站和客户端测试规格。[W04]

不要记录隐藏推理；展示可核对的事件事实和公开摘要。外部文本与 Markdown 默认为惰性内容，链接明确标示目的地，不渲染任意 HTML/脚本。诊断导出先显示将包含的类别、时间范围和脱敏变更，让用户决定是否保存；默认不远程上传。

## 客户端完成标准

在真实签名发行物上跑通新 profile、任务、批准、取消、查看产物、配置冲突、关闭重开、事件补齐和 UNKNOWN 核对。展示层单元测试、Rust command 测试和无头截图只能补充这些证据。若某个自动化工具桥接只供测试，release 构建必须证明没有开放该能力。

## 桌面端 UI/UX 深度优化七项规范（V1-061 至 V1-067）

在 `apps/desktop` 初版基础上，统一版 v1.0.0 直接交付完整商业级桌面体验：[R04、R25、W03、W04]

- **零配置首开向导（`V1-061`）**：自动检测/一键启动后台 Daemon、绑定工作区、通过 Rust 原生接口直写 Keychain 密钥或探测本地 Ollama、运行 Doctor 自检。
- **Rust Keep-Alive 连接池与 SSE 实时增量流（`V1-062`）**：移除 `setInterval(refresh, 1800)` 的 HTTP/1.0 五接口轮询，改为长连接订阅 `/v1/tasks/{id}/events` SSE 实时推送并处理 `410` 快照恢复。
- **双栏语法高亮 Diff 审批台与自适应 DAG 因果图（`V1-063`, `V1-064`）**：支持 Unified/Split 代码着色对比、新旧 `sha256` 徽章、实时 TTL 倒计时，以及支持缩放/平移/筛选的层次化 DAG 执行图。
- **图形化 `UNKNOWN` 核对向导、macOS MenuBar 常驻托盘与深色模式（`V1-065` 至 `V1-067`）**：在 UI 内三步完成未知副作用核对；顶部菜单栏常驻显示待审批角标与【紧急停止】按钮；提供符合 WCAG 2.2 AA 的深色/浅色双主题与 `Cmd+K` 全局快捷键。
