## 关键路径

范围与证据 → 真实有界 runtime → 取消/恢复/秘密/隔离 → 客户端与本地服务监管 → 可安装包与签名迁移 → 真实集成与真机 beta → RC 汇总门禁。文档与官网从范围/能力事实源开始并行，在发布前与最终产物核对。

详细 DAG 由 `tasks/backlog.json` 的 `depends_on` 得出；原 `OB-001` 至 `OB-096` 共 96 项任务已 100% 映射至上述 `legacy_ids`。
