# Contributing to OpenBot

感谢参与。提交前先读现有 AGENTS.md、CLAUDE.md、当前 task card 和安全边界；此贡献指南不改变这些合同。

## 本地验证

使用 pyproject.toml 与锁文件要求的 Python/uv 环境：`uv sync --locked`，然后 `.venv/bin/python scripts/verify.py`。可选 SDK、原生容器、真实服务和桌面测试按所属任务单独运行，并在 PR 中列明范围和阻塞条件。

## 变更范围

一次 PR 处理一个可理解的问题或交付切片。涉及行为修复时，提供失败复现和相关回归；文档修改验证链接、命令与实际界面。公共合同、迁移、依赖锁、权限或重试规则变化需要相应设计说明。

## 核心不变量

- 所有工具效果经过同一 Broker；模型和工具元数据不授予权限。
- 审批、claim、dispatch 与结果独立；CONSUMED 不复活。
- UNKNOWN 需要核对，不盲目重放非幂等动作。
- UI、CLI、飞书共用控制面；回放仅查询事实。
- 缺隔离能力不回退任意宿主执行；秘密不进入源代码、参数、普通日志或诊断包。

## PR 应说明

具体问题、行为变化、原 OB/V1 任务ID、测试命令与结果、真实/合成证据范围、迁移/兼容影响、已知限制。不要将缺环境或 skip 写成 PASS。

## 安全与许可

不要在公开 Issue/PR 上传秘密或真实业务数据。SECURITY.md 尚需补充并验证私密安全报告入口；入口可用前，不公开漏洞细节或上传敏感材料。项目自身许可完成核对后，在本指南链接实际根 LICENSE；第三方摘取须保留来源、许可、修改和 NOTICE。
