# 获取帮助

先查看 getting-started、troubleshooting、当前支持矩阵和已知问题。故障报告请提供版本/提交、系统/CPU架构、安装来源、最小复现、预期/实际以及脱敏日志摘要。

“结果待核对”不等于没有发生效果。先停止后续动作，保留 operation/attempt 标识，再按恢复指南核对，避免重复提交危险动作。

不要粘贴 API key、token、cookie、私密聊天、完整数据库或未预览的诊断包。SECURITY.md 尚需补充并验证私密安全报告入口；入口可用前不公开敏感漏洞细节。普通问题使用仓库 Issue 模板。

维护者应在发布前补齐实际支持版本、分诊负责人和可承担的响应目标；当前不虚构邮箱、团队或服务时限。
