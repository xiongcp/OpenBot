## 页面组件规则

- 首页、下载页、文档与GitHub链接读取同一版本事实源。
- 语言切换保留对应页面；关键安装、安全和恢复页面不能仅依赖未翻译fallback。
- 404提供文档搜索和首页入口；搜索无结果显示模型、安装、停止/恢复等常用路径。
- 截图标明实际产品版本和合成场景；规划线框明确写“设计提案”。
